## 로컬 시작

Node.js 22.12 이상을 사용합니다. 개발 worktree에서 실행하세요.

```sh
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:8787 을 열고 **로컬 작업실 열기**를 누릅니다. 로컬 설정의 공개 테스트 값은 실제 인증 정보가 아닙니다. 실제 카카오 자격 증명 없이 시작할 수 있습니다.

1. 요약 홈에서 다음 예약·확인할 결과를 확인하고 **카드 만들기**를 엽니다. 보관함에서는 표현·뜻 검색, 상태·유형 필터, JSON/예제 가져오기를 사용할 수 있습니다.
2. 미리보기와 내용을 확인하고 검토 체크 후 PNG를 저장합니다.
3. 저장 후 **이 카드 예약하기**를 누르거나 발송 예약에서 **새 예약**을 엽니다. 검토 완료 카드와 순서, 2분 이후의 시각을 선택합니다.
4. 예약 발송 미리검증을 실행하고 발송 기록을 확인합니다. 이 동작은 카드 목록을 소비하지 않습니다.

목록은 100개씩 불러오며 **더 불러오기**로 이전 자료에 접근합니다. JSON 백업도 파일당 최대 100개입니다. **다음 JSON 백업** 버튼이 없어질 때까지 모든 파일을 보관하고, 복원할 때 각 파일을 한 번씩 가져옵니다.

운영 예약은 Worker의 Cron Trigger가 실행합니다. 인증·갱신은 비공개 `en-card-automation` DO, 준비·발송은 비공개 `en-card-delivery`에 연결합니다. **수동 예약만 사용하는 설치에도 인증 DO가 필요하며 AI 기능은 off로 유지할 수 있습니다.** 로컬 개발 서버는 테스트용이며 PC를 끄면 중단됩니다. 실제 클라우드 실행 조건과 DO→발송 Worker→주 Worker 배포 순서는 [설정·배포 절차](docs/SETUP.md)에 있습니다.

## 검증

최신 제품 검증은 [10월 4일 무인 제작·수신](docs/evidence/AI_AUTOMATION_TRIAL_2026-10-04.json)과 [실제 토큰 갱신](docs/evidence/AI_TOKEN_REFRESH_VERIFICATION_2026-10-04.json)입니다. 실제 발송 때 일반 주 Worker CPU4.269ms·발송 Worker3.787ms를 관측했습니다. 한 번의 측정은 미래 모든 실행의 최댓값이나 무료 과금 보장이 아닙니다.

선행 [SQLite DO 무료 이미지 생성 시험](docs/AI_CARD_AUTOMATION_DURABLE.md)은 **1080×1080 PNG20장**의 JSON→PNG→임시 D1/KV 저장·회수를 검증한 10월 3일 기록입니다. DO CPU78~474ms·일반 입구0~1ms, 이미지 경로 로그80/80이며20장 모두 기준 PNG와 같습니다. 전체89/90로그 중409 입구1건 CPU는 미확인으로 보존합니다. 당시 제품 연결은 미완료였고 시험 자원은 정리했습니다. 이후 제품 검증과 합산하지 않습니다. 로컬 재현은 `npm run test:automation:durable`입니다.

선행 성능 후속인 [중간 픽셀 복사 제거](docs/AI_CARD_AUTOMATION_REFERENCE.md)는 native 전체 반복40.055→41.534ms로 늘어 기본 적용하지 않았습니다. PNG4,200개 동일·관련73테스트와 검증기6회귀·빌드·리뷰를 통과했습니다. 앞선 [N3](docs/AI_CARD_AUTOMATION_BLOCKS.md)·[N2](docs/AI_CARD_AUTOMATION_BINARY.md)·[N1](docs/AI_CARD_AUTOMATION_RPC.md) 결과도 보존합니다.

성능 조사 자료는 [기존 25시도·추가 5후보 보고서](docs/AI_CARD_AUTOMATION_PERFORMANCE.md)에 정리했습니다. 원격 CPU 34집계·로컬 측정 785행과 검색·필터가 있는 차트 5개를 제공하며, 보존용 [단일 HTML](docs/performance/ai-png-performance.html)도 브라우저에서 열 수 있습니다. 이 시각화는 N1/N2/N3 구현 전의 조사 스냅샷이며 최신 후보 측정은 위 후속 보고서를 따릅니다.

일반 Worker에서 수행한 선행 시험88장의 CPU 실패와 로그 누락은 과거 결과로 유지합니다. 조립 함수 분리·native CRC의 첫 조립 로컬 중앙값13.82→12.74ms는 원격 CPU가 아니었습니다. 이번 DO20장을 합친 원격 누적은108장이고 제품 기본1080규격을 유지합니다. 선행 근거는 [조립 개선 로컬 비교](docs/AI_CARD_AUTOMATION_BLIT.md)를 확인하세요.

```sh
npm run build
npm run check:free
npm test
npx playwright install chromium webkit
npm run test:e2e
```

`build`에는 타입 검사·Vite 빌드·폰트 준비와 세 Worker의 배포 dry-run이 포함됩니다. 별도 검사는 `npm run deploy:dry-run`, `npm run deploy:delivery:dry-run`, `npm run deploy:automation:dry-run`입니다. 이 명령은 원격에 배포하지 않습니다. E2E는 8787 포트와 별도 `.wrangler/e2e-*` 저장소를 사용하므로 개발 서버를 종료한 뒤 실행합니다.

화면 주소는 `#/home`, `#/editor`, `#/library`, `#/schedules`, `#/history`, `#/settings`입니다. 화면 이동 중 작성 내용은 유지되지만 브라우저를 닫으면 저장하지 않은 입력은 사라집니다. 아이폰에서는 하단 **더보기**로 제작·설정 화면에 접근합니다. Chromium은 기존 로컬 D1 회귀와 새 UI 검증을, WebKit은 새 UI 검증을 실행합니다. WebKit의 모의 API 검증은 실제 아이폰·카카오 연동 확인과 구분합니다. 개편 범위는 [계획](docs/UI_UX_REDESIGN_PLAN.md)과 [검토 기록](docs/UI_UX_REVIEW.md)을 따릅니다.

## 운영 및 비용 조건

React/Vite, 브라우저 Canvas, Workers Free + Static Assets, SQLite Durable Objects Free, D1 Free, KV Free, 카카오 공식 나에게 보내기 API를 사용합니다. 선택적인 AI 제작은 확인된 Google/Groq Free 계정과 기존 Site Secret을 사용합니다. 유료 AI API·R2·Cloudflare Images·유료 메시지·별도 도메인 의존성이 없습니다. 무료 한도 초과 시 멈추며 유료 상품으로 전환하지 않습니다. **실제 계정의 Free 플랜 확인은 별도로 필요합니다.** 마지막 계정 플랜 재조회는 권한 제한으로 확인하지 못했으며, 기존 무료 확인과 구성 검사만으로 현재 계정 청구를 보장하지 않습니다.

무료 나에게 보내기는 **푸시 알림·알림음이 없습니다**. 한 카드당 이미지 피드 메시지 한 개로 발송하며 원본 보기 링크를 제공합니다. 일반 사진 첨부나 여러 사진의 묶음 전송과 다릅니다. 인증 만료·제공사 장애·무료 한도로 늦어지거나 멈출 수 있으며 정시 도착·무중단·영구 무료를 보장하지 않습니다.

이미지 URL을 아는 사람은 해당 카드를 볼 수 있습니다. 토큰·예약·카드 목록은 공개하지 않습니다. 발송 결과가 불명확하면 자동 재발송하지 않고 사용자 확인을 기다립니다.

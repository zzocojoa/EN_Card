# AI 카드 자동화 구현 리뷰

## 오늘 추가 한 장 시험 — 2026-10-04

사용자가 오늘 새 AI 카드 한 장 추가 시험과 기존 기록 보존 기능을 선택했다. `review`의 데이터 마이그레이션·보안·유지보수·성능·API·테스트·적대적 관점을 같은 모델의 별도 검토자로 적용했다. 기존 전체 구현 리뷰에 대한 후속이며 교차 모델 검토로 주장하지 않는다.

- 0015는 구버전 DO와 호환되지 않는다는 지적을 배포·복귀 절차에 반영했다. 주 Worker 쓰기/Cron 차단 후 암호화 백업·마이그레이션·기존 행/FK 비교·새 DO·새 주 Worker 순서로 적용했다.
- 최근 기록 조회의 인덱스 누락을 수정했다. `automation_history(day DESC,due_at DESC)` 사용을 SQLite 실행 계획으로 확인했다.
- 시험 시작 시 sending/unknown 차단 회귀가 빠져 추가했다. 거절 후 설정·기록 보존, 명시적 unknown 종료 뒤 허용을 검증했다. 재검토 및 적대적 검토 결과 남은 코드 결함은 없었다.

제품35개(33개 전체 통과 후 추가2개 및 마이그레이션1개 재확인), 실제 workerd/relay/RPC/무료구성44개, Site 프록시·번들15개, Chromium·WebKit2개가 통과했다. 타입·전체 빌드·기본/운영 무료구성·대상 lint·format/diff 검사도 통과했다. 로컬 외부 응답은 모의다. 최초 SQL 주석의 fixture 평탄화 오류는 블록 주석으로 수정 후 재검증했다. Sites helper의 Windows npm 실행/Node22 패키징 실패는 직접 npm build와 Node24 패키징으로 복구했으며 source helper의 push/아카이브 검증 및 v112 게시 성공을 확인했다.

새 실제 시험은 별도 등록 근거로 관리한다. 등록 성공을 실제 AI 제작·수신·PC 종료·CPU 검증 완료로 표시하지 않는다.

## 인증 CPU 분리 후속 — 2026-10-04

실제 토큰 갱신 tick의 CPU 14.004ms 확인에 따라 비공개 DO RPC로 인증 처리를 분리했다. `review`의 보안·테스트·유지보수·성능·API 계약·적대적 관점을 별도 검토로 적용했다. 같은 Codex 모델을 사용했으며 교차 모델 검증으로 주장하지 않는다.

- 테스트 검토: Free/live 모드와 잘못된 RPC 입력의 차단 회귀가 빠진 점을 지적했다. D1/카카오 호출 0회 및 DB 예외 상세 비노출을 포함한 9개 테스트를 추가했다.
- 적대적/API 계약 검토: AI off 설정이 DO dry_run을 강제해 수동 발송까지 막는 충돌을 지적했다. 발송 모드를 main과 일치시키고 AI 활성 조건을 분리했으며, 설정 회귀와 DO 선배포·AI off/live 운영 안내를 수정했다. 중복 지적은 한 원인으로 합쳤다.
- 보안·유지보수·성능 추가 결함은 없었다. 지적 사항 재검토 후 남은 코드 결함은 0건이다. 6파일116개 인증/복구/제품/RPC 검증, 입력 차단9개, 구성14개가 통과했다(총139개, 서로 다른 테스트). 실제 workerd RPC를 사용하되 제공사 응답은 모의이며 실제 카카오 재갱신/발송과 CPU 개선 검증은 별도다.

타입 검사·전체 빌드·기본/운영 무료 구성 검사를 통과했다. 새 배포본의 실제 CPU와 PC 종료 중 새 AI 제작 시험은 아직 완료로 표시하지 않는다.

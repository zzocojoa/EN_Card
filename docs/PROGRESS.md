검증의 최신 명령·통과 범위와 미실시 항목은 [VERIFICATION.md](VERIFICATION.md)에만 기록합니다. M0~M4의 기존 로컬 검증 후 최종 리뷰에서 누적 중지 이력 처리 결함이 추가로 확인되어 수정 선택을 기다리고 있습니다. 실제 운영 완료를 의미하지 않습니다.

현재 배포 선행 조건은 Cloudflare·Kakao Developers 계정 준비입니다. Wrangler는 미로그인 상태이며 원격 리소스와 Free 자격은 미확인입니다. 가입과 앱 설정 순서는 [SETUP.md](SETUP.md)의 계정 준비 항목을 따릅니다. PR #1은 열려 있으며 병합·배포·실제 발송은 미실시입니다.

최종 리뷰의 미해결 P2: 0008까지 누적된 중지 카드가 45장인 DB에 0009를 적용하면 전체 제외는 요청의 40장 제한으로 실패하고, 40장 부분 제외도 전체 목록 비교로 거부되어 재개가 차단됩니다. 권장 수정은 화면과 API에서 최대 40장씩 원자적으로 처리하고 미결정이 남으면 재개 차단을 유지하는 것입니다. 현재 사용자 선택 대기이며 아직 수정하지 않았습니다.

## 판단 근거

- 브라우저에서 PNG를 렌더링하고 Worker는 인증·저장·예약·발송만 담당합니다.
- 운영 진입점과 로컬 인증 진입점을 분리하여 테스트 세션 기능이 운영 번들에 포함되지 않도록 합니다. mock은 테스트의 독립 DB/KV에서만 호출합니다.
- D1 batch와 조건부 SQL·트리거로 회차·예산을 원자적으로 갱신합니다. KV와 D1 사이에는 트랜잭션이 없으므로 업로드 실패 용량은 확인·정리 전까지 보존합니다.
- 직접 네트워크를 호출하는 서비스는 카카오 인증·본인 메시지 API뿐입니다. 무료 플랜 및 실제 CPU 사용은 계정·원격 환경에서 별도로 확인해야 합니다.
- 네트워크 응답 유실 후 전달 여부를 증명할 수 없어 unknown을 자동 재전송하지 않습니다.

- 예약 재개·수정의 각 변경 ID로 경합을 격리하고, 재개 시 남은 카드만 새 버전에 옮깁니다. 수정은 편집 당시 소비 위치도 비교하여 발송 진행 뒤 오래된 목록이 다시 등록되지 않게 합니다.
- 저장·PNG 복원 중에는 편집 대상을 바꾸지 못하며, 재연결 전의 늦은 토큰 갱신 실패는 새 연결과 예약을 중단하지 않습니다.
- 목록은 인덱스와 시각·ID 커서를 사용합니다. 가져오기 한 파일은 단일 SQL로 저장하고, 100개를 넘는 백업은 다음 파일로 이어집니다.
- 운영 진입점, 모의 발송, 브라우저 흐름의 요구사항별 근거는 VERIFICATION.md의 대조표에 있습니다.

## R1·R2 유지보수: 로컬 구현·검증 완료

- 결과 불명이 남은 예약의 버전 변경을 차단하고, 수신 여부를 확정하지 않고 재전송을 포기하는 종료와 감사 이력을 제공한다. 이전 버전 자료도 복구하며 종료로 예약을 자동 활성화하지 않는다.
- 토큰의 명시적 일시 오류는 D1에 재시도 횟수·시각을 저장한다. 인증 무효·응답 불명·설정 오류와 구별하며 새 인증의 버전·잠금을 보호한다.
- 판단: unknown은 사실 기록으로 보존하고 resolution으로 사용자 종료를 분리한다. 토큰 응답 유실은 회전 여부를 증명할 수 없어 자동 재시도하지 않는다. 503/temporarily_unavailable는 이번 요청의 좁은 허용 조건이며 실제 제공사 응답 검증은 남아 있다.
- 상세 완료 근거·마이그레이션 영향은 [R1_R2_FIX_REPORT.md](R1_R2_FIX_REPORT.md)에 정리한다. R3·R4의 현재 근거는 아래 보고서에 있으며 원격 배포·실제 수신은 미실시다.

## R3·R4와 M5 준비: 로컬 검증 완료

- 중지할 미발송 목록을 확인하고, 원본과 연결된 새 미래 예약 또는 명시적 제외를 선택한다. 현재 회차의 미발송 2장과 미소비 목록 5장을 구분하며 이미 보낸 3장은 되살리지 않는다. 호출 이력·고정 이미지·원본 이력을 보존한다.
- 결정 근거: 외부 접수 가능성을 배제할 수 없는 이력은 자동 복구하지 않는다. 복구 선택 전 원본별 결정 보호와 이미지 삭제 보호를 적용하며 R1의 unknown/sending 차단을 유지한다. 취소된 원본은 재활성화하지 않는다.
- PNG는 전체 청크 경계·핵심 순서·IHDR·IDAT·IEND·모든 CRC를 검사한다. 1MiB 입력을 순회하는 구조 검사이며 압축 해제·전체 픽셀 유효성은 보장하지 않는다. 새 정상 fixture는 실제 압축 해제가 가능한 PNG다.
- 기본 dry_run은 유지하고 명시한 live 파일에도 동일한 무료 구성을 검사한다. 검사 대상 파일과 SHA를 출력하고 배포나 발송을 수행하지 않는다.
- 0001~0008은 보존하고 0009를 후속 적용한다. 원격 실행 절차와 계정/Secret 입력 표는 SETUP.md, 중단·복원은 OPERATIONS.md에 있다. 실제 Free 계정과 CPU, OAuth 갱신, 휴대전화 수신·PC 종료 검증은 남아 있다.
- 변경·실패 재현·검증의 상세 근거: [R3_R4_M5_READINESS.md](R3_R4_M5_READINESS.md). 검증된 변경은 보고서와 함께 codex/development의 후속 커밋에 묶는다. GitHub 반영과 실제 운영 배포는 구분한다.

## Windows 무료 구성 테스트 준비 코드 호환성 — 2026-09-30

- tests/free-config.test.ts의 node_modules 연결을 Windows에서는 junction으로 생성하며 realpath로 실제 설치 디렉터리와 동일한지 검증한다. 기존 검사 조건과 제품 코드는 유지한다.
- 실패했던 focused 8개와 최종 전체 Vitest 177개가 모두 통과했다. 최종 타입 검사·웹 빌드·Worker dry-run·무료 구성 검사 및 Chromium E2E 10개도 통과했다. 첫 전체 검사의 연결 중단 기록은 보존하며 최종 단계별 종료코드는 모두 0이다.
- OS 개발자 모드·권한·보안 설정과 lockfile은 변경하지 않았다. 45장 복구 결함은 별도 미해결 범위로 유지한다. 상세 근거는 VERIFICATION.md의 Windows 추가 기록을 따른다.

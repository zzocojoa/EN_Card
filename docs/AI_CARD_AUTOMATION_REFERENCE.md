# PNG 조립의 중간 픽셀 복사 제거

2026-10-03 / `codex/ai-card-automation` / 기반 `ad875e8`

**구현·로컬 비교를 완료했으나 기본 조립에는 적용하지 않는다.** 중간 픽셀 복사는 없어졌지만 전체 생성 시간이 일관되게 줄지 않았다. 함수 분리+native CRC 경로의 조립 반복 평균은4.707→4.271ms였으나 전체 반복은40.055→41.534ms였다. 원격 CPU 시험은 추가하지 않았으며, 마지막 원격의 CPU 초과·로그 누락과 AI 자동화2~5단계 미완료 상태는 유지한다.

## 변경한 처리

기존에는 글자 자료 검증 뒤 `mergeAtlases`가 선택한 모든 글자의 픽셀을 새 연속 버퍼에 복사하고 위치를 다시 계산했다. 이번 후보는 각 글자의 원본 `Uint8Array`와 기존 offset을 참조해 최종 PNG 행에 바로 그린다.

```text
기존: 글자 검증 → 픽셀 병합·복사 → 카드에 그리기 → 압축·PNG 검증
후보: 글자 검증 → 원본 참조 색인 → 카드에 그리기 → 압축·PNG 검증
```

- `atlas-reference.ts`: 픽셀 복사 없이 글자·원본 버퍼 색인을 만든다. 중복 글자와 선택 픽셀 총2MiB 제한을 유지한다. 색인은 여전히 필요하다.
- `atlas.ts`: 내부 전용 `RenderAtlas.pixelSources`를 지원한다. 참조 버퍼별 painter는 한 번의 렌더 안에서만 생성·보관한다. 원본 view의 byteOffset과 글자 offset, 그리는 순서·겹침·투명도·색상·PNG 검사를 보존한다.
- `atlas-pipeline.ts`: 기존 메타데이터·알파값 검증이 끝난 뒤 명시적 `referencePixels` 옵션으로만 후보를 선택한다. 기본값은 복사 방식이다. 요청 본문으로 이 옵션이나 참조 색인을 지정할 수 없다.
- `atlas-reference-worker.ts`·`wrangler.atlas-reference.jsonc`: 고정 예제만 처리하는 비공개 시험 구성이다. 배포 설정은 참조+함수 분리/native CRC 후보이며 운영 설정이 아니다.
- `reference-inputs.ts`·`research-reference-workerd.mjs`: 실제 글자 자료와 보존 PNG로 네 경로를 비교한다. `scripts/check-automation-reference.mjs`는 저장된 원시 행과 해시를 별도로 재검증한다.

10개 해상도/예제 조합에서 제거한 병합 버퍼의 할당·복사량은 한 장당 **31,454~71,998바이트**다. 전달 프레임, 메타데이터 처리, 글자 그리기, 압축, PNG 검증은 남아 있다. 전체 메모리 최고 사용량이나 Cloudflare CPU 감소량을 측정한 값은 아니다.

## 동일 실행에서 비교한 결과

모두 **로컬 경과 시간(ms)**이며 Cloudflare 요청 CPU가 아니다. `native`는 앞서 비교한 함수 분리 painter와 native CRC를 함께 사용하는 경로다. 복사 제거 효과는 같은 그리기 방식의 두 열끼리 비교한다.

| 측정                | 기본 그리기·복사 | 기본 그리기·참조 | native·복사 | native·참조 |
| ------------------- | ---------------: | ---------------: | ----------: | ----------: |
| 첫 조립 중앙값      |           18.779 |           22.512 |      21.272 |      20.085 |
| 조립 반복 평균      |            4.401 |            4.480 |       4.707 |       4.271 |
| 첫 전체 생성 중앙값 |           50.484 |           51.078 |      50.440 |      50.891 |
| 전체 생성 반복 평균 |           40.635 |           39.946 |      40.055 |      41.534 |

native 참조의 조립 개선은 전체 경로에서 유지되지 않았다. 전체 반복이 빨라진 짝은 기본 그리기21/40, native16/40이다. 첫 전체 생성은 각각23/40,20/40이다. 표본 전체에서 일관된 개선을 입증하지 못했으므로 기존 복사 경로를 유지하고 참조 경로는 재현 가능한 실험으로 보존한다. 원본 버퍼를 찾는 추가 비용이 절감을 상쇄할 수 있다는 설명은 가설이며, 이번 측정으로 CPU 원인을 확정하지 않는다.

### 측정 범위

- 5예제×800/720, 두 그리기 방식×복사/참조, 조립 단독/전체 경로,4회 순환 순서: **320개 새 로컬 workerd 실행 환경**.
- 같은 입력·방식이 네 측정 위치에 각각 한 번씩 오도록 순서를 배치하고 입력 순서도 교대했다.
- 각 환경에서 첫1회·안정화2회·반복10회. 각 측정 범위/방식마다 첫40회와 반복400회다. 별도 smoke4환경을 포함해 실제 계산 PNG **4,200개**가 보존 기준과 전체 바이트 일치했다.
- 조립 단독은 실제 준비 묶음을 입력하고 글자 준비/수집을 제외한다. 전체 경로는 실제 로컬 정적 자산 읽기·글자 준비·인증 입구·수집·조립을 포함한다. 사전 완성 PNG를 대신 반환하지 않는다.
- 호스트 요청 전달과 응답 본문 읽기를 포함하고, 바이트 대조와 실행 환경 시작/common 모듈 초기화는 타이머에서 제외했다. 설정 시간은 별도 기록한다. 첫 조립을 플랫폼 전체 cold start로 부르지 않는다.
- 복사 대조군도 이번에 추가한 공통 renderer의 선택 분기를 포함한다. 과거 보고서의 절대 시간과 직접 이어 붙여 개선율을 계산하지 않는다.
- 프로파일러·이상치 제거를 사용하지 않았다. 측정 중 이 작업의 테스트·빌드·다른 벤치마크는 실행하지 않았다. 순서 균형이 호스트 환경의 모든 변동을 제거하거나 통계적 유의성을 증명하지는 않는다.

근거: [원시320행·8집계·4짝비교](evidence/AI_PNG_REFERENCE_LOCAL_2026-10-03.json), [작업량·로컬 연동·거부 기록](evidence/AI_PNG_REFERENCE_WORKER_2026-10-03.json). 소스19개·읽은 자산247개의 SHA-256을 측정 전후 및 독립 검증기에서 대조했다.

## 검증·리뷰

관련5파일 **73테스트 통과**: 실제 한영/동적 카드의 PNG,1080/800/720, 원본 view/offset, 네 painter의 겹침·색상·빈 글자·투명도, 원본 불변, 참조 누락·중복·총량과 손상 프레임을 확인했다. 실제 로컬 Worker smoke는40 PNG 일치와 잘못된 요청32건 거부를 확인했다.

리뷰에서 후처리 검증기가 양쪽 증거의 해시 목록이 함께 비어 있으면 통과할 수 있는 결함을 발견했다. 필수 소스·자산·variant·해시 형식 및 경로 검사를 추가하고, 별도 **6개 회귀 테스트**를 통과했다. 타입 검사·Vite·제품2개와 시험1개 Worker dry-run·무료 구성 검사도 통과했다. 전체 제품 Vitest/E2E와 실제 AI/카카오를 새로 검증한 것은 아니다.

테스트·성능·보안·유지보수 전문 검토와 독립 적대적 검토를 수행했다. 전문 테스트 검토는 테스트 원문, 적대적 검토는 테스트·fixture 요약 범위다. 같은 모델의 검토이며 Claude/교차 모델/별도 CLI 통과로 주장하지 않는다. [리뷰 기록](AI_CARD_AUTOMATION_REVIEW.md)을 따른다.

## 재현·남은 조건

전체 글자 자산이 없는 환경에서는 [기존 준비 명령](AI_CARD_AUTOMATION_OPTIMIZATION.md#재현-명령)을 먼저 실행한다. 아래 비교는 같은 이름의 증거 파일을 다시 쓰므로 기존 증거를 보존한 checkout에서 재현한다.

```powershell
npm test -- tests/automation-reference.test.ts tests/automation-atlas.test.ts tests/automation-optimized.test.ts tests/automation-blit.test.ts tests/png.test.ts tests/automation-reference-evidence.test.mjs
npm run build
npm run check:free
npx wrangler deploy --config experiments/automation-png/wrangler.atlas-reference.jsonc --dry-run
node experiments/automation-png/research-reference-workerd.mjs
node scripts/check-automation-reference.mjs
```

새 원격 배포·PNG 생성·계정 조회·AI·카카오 호출은 없었다. 유료 의존성이나 운영 자원 변경도 없다. 원격 PNG 누적88개는 유지하며 이번 구성 검사 통과는 계정 Free 자격이나 실제 CPU 적합성을 증명하지 않는다.

다음 미완료 항목은 첫 조립뿐 아니라 준비·수집을 포함한 **각 원격 호출의 CPU 조건과 누락 로그 확보**다. 이번 변경만을 근거로 원격 재시험이나 무인 활성화를 진행하지 않는다. [마지막 실제 CPU 진단](AI_CARD_AUTOMATION_DIAGNOSTIC.md)과 기존 전체 AI 자동화2~5단계 미완료 상태를 유지한다. 무인 PNG 구조를 변경할지, 추가로 검증할 구체적인 병목 가설이 있는지 판단해야 한다.
